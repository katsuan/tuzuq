📅カレンダー・ふりかえり

日を押すと○をつけ外しできます（「🗓 すべて」では、その日のようすが出ます。全部できた日がいちばん濃い色）。🍚・🏋️・💬 の自動の○は、しょくじ・キロっく・記録ボットの記録で決まります（同じブラウザで開いたときだけ読めます。キロっくは LINE の中）。一度読んだ日は、もとの記録が消えても残ります。

週のはじまり
🔔カレンダーでお知らせ

毎日決まった時刻に、カレンダーが知らせてくれます。予定から、つづくを開いて○をつけられます。

iPhone はファイルを開いて「すべてを追加」。1つずつ入れるときは「Google」（毎日くり返す予定として入ります）。止めるときは、カレンダーの予定を消します。

💬LINE でも記録（自分用）

自分の記録ボットにも送りたいときに。ボットの LINE の ID を入れると、習慣ごとに「送る文」を決められます。今日の○をつけると「💬 LINE でも記録」が出て、押すとボットのトークが送る文入りで開きます（送るのは自分）。

@ から始まる ID を入れてね（例：@123abcde）

GAS のウェブアプリの URL（…/exec）を入れてね

自分の記録ボット（LOgBOT の複製）の URL です。GitHub は、その GAS につないだときだけ。つなぎ方・LINE の情報の使い方

💬 いまは LINE の中で開いているので、送る文のある習慣は、今日の○を押すだけで記録ボットに入ります（トークに切りかえなくてよい）。ボットで記録した日にも○が出ます（黄色。つづくでは外せません）。習慣を直すと「送る文」を決められます。

🔒記録の控え

記録はこの端末（ブラウザ）の中だけにあります。機種変更やブラウザのデータを消す前に、控えを書き出しておいてください。
