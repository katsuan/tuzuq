# ✅ つづく 〜TuzuQ〜

できた日に○をつけるだけの習慣カレンダー。何日つづいたか・ひと月の○が見える。名前は「つづく」。英字は TuzuQ（「つ・づ・く」を tu・zu・Q と書き、「く」を Q にする。おくるん＝OQRN・しょくじ＝ShoQuji と同じ作り方）。キャッチコピーは「きょうのできたが、あしたにつづく」。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/tuzuq/ （2026-10-23 公開。noindex のまま。Q ツール（ConneQt の一覧）・ポートフォリオには載せない。英字ははじめ TsuduQ（tsuduq）だったが、同じ日に TuzuQ（tuzuq）へ変えた）

## できること

- ✅ きょうの○：習慣ごとに、右の大きな丸で今日の○をつけ外し。下の7つの丸（この1週間）も押すとつけ外しできる。続いた日数（🔥）と、今日いくつできたか（2 / 3）
  - 今日まだ○がなくても、昨日まで続いていれば日数は消えない（今日つければ続く）
- 🌱 はじめは「よくある習慣」（水を2L・8000歩・読書・ストレッチ・フロス・日記）を押すだけでふやせる
- ➕ 習慣をふやす・直す：名前・しるし（絵文字）・ほかの Q ツールとつなぐか。12こまで。↑↓で並べかえ、✕ ですぐ消せる（下に出る知らせの「元に戻す」で戻せる）
- 🍚 ほかの Q ツールとつなぐ：同じサイト（katsuan.github.io）なので、しょくじの記録（localStorage の `shoquji:v1`）を読んで、記録した日に自動で○（黄色）。自動の○は、つづくでは外せない
- 📅 カレンダー・ふりかえり：習慣ごとのひと月の○（押すとつけ外し）、この月の日数と割合・いま続いている日数・いちばん長く続いた日数
- 💬 LINE で送る：おくるんのお知らせカード（`OQRN.cardUrl`）に、今日の○の一覧と続いた日数を渡す。色はロゴの青（#2F80D8）、ボタンは「✅ つづくで○をつける」。流入口は `from=tuzuq`
- 🔒 記録の控え：書き出し（スマホは共有シート、パソコンはダウンロード）・読みこみ（同じ習慣は○を足す、ほかは加える）、すべて消す

## 記録の置き場所

この端末（ブラウザ）の localStorage の `tuzuq:v1` だけ。サーバーには送らない（前の名前の `tsuduq:v1` が残っていれば、それを読む）。

- `habits`：`[{ id, name, emoji, link, at }]`（`link` は `"shoquji"` か null）
- `done`：`{ 習慣の id: ["YYYY-MM-DD", ...] }`（自分でつけた○の日。自動の○はここに入れず、そのつど読む）

## つなぐツールをふやすには

`js/store.js` の `LINKS` に足して、`linkedDays()` にその記録から日付を取り出す書き方を足す。ぽもくるは今は回数を残していないので、つなぐなら、ぽもくる側で「集中した日」を残すところから。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（スマホ前提。入力欄は 16px 以上、ページにも背景色）。部品はおくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`・`ui.js`）。`style.css` には、つづくの色と、つづくにしかない見た目だけ |
| `app.js` | 操作（○をつける・習慣をふやす・直す・カレンダー・カード・控え） |
| `js/store.js` | 記録の保存・つなぐツールの読みこみ・控え |
| `js/stats.js` | 計算（日付・続いた日数・いちばん長く続いた日数・ひと月のカレンダー） |
| `tools/icon.py` | アイコン・ロゴ・OGP |

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q はカレンダーの○：白い輪の中にチェック、しっぽは右下からのびて輪の中に○をつけにいく黄色い手（ふちなし・ひとまとまり）
- 色は青（ほかの Q のツールと重ならない色）

## 公開するときにすること

1. GitHub に `katsuan/tuzuq` を作って push し、Pages を開く
2. 確かめがすんだら `index.html` の noindex を外す
3. おくるん（line-share）の `data/hub-links.json` に `key: "tuzuq"` を足す（グループは「毎日・あそび」）。`backup/app.js` の一覧に `["tuzuq:", "つづく", "tuzuq"]` を足す
