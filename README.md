# ✅ つづく 〜TuzuQ〜

できた日に○をつけるだけの習慣カレンダー。何日つづいたか・ひと月の○が見える。名前は「つづく」。英字は TuzuQ（「つ・づ・く」を tu・zu・Q と書き、「く」を Q にする。おくるん＝OQRN・しょくじ＝ShoQuji と同じ作り方）。キャッチコピーは「きょうのできたが、あしたにつづく」。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/tuzuq/ （2026-10-23 公開。ConneQt の一覧・ポートフォリオにも載せた。英字ははじめ TsuduQ（tsuduq）だったが、同じ日に TuzuQ（tuzuq）へ変えた）

## できること

- ✅ きょうの○：習慣ごとに、右の大きな丸で今日の○をつけ外し。下の7つの丸（この1週間）も押すとつけ外しできる。続いた日数（🔥）と、今日いくつできたか（2 / 3）
  - 今日まだ○がなくても、昨日まで続いていれば日数は消えない（今日つければ続く）
- 🌱 はじめは「よくある習慣」（水を2L・8000歩・読書・ストレッチ・フロス・日記）を押すだけでふやせる
- ➕ 習慣をふやす・直す：名前・しるし（絵文字。並んだものから選ぶか、「ほかのしるし」に好きな絵文字を1つ入れる）・ほかの Q ツールとつなぐか。12こまで。↑↓で並べかえ、✕ ですぐ消せる（下に出る知らせの「元に戻す」で戻せる）
- 🍚🏋️ ほかの Q ツールとつなぐ：同じサイト（katsuan.github.io）なので、しょくじの記録（localStorage の `shoquji:v1`）・キロっくの記録（`liff-workout-history`）を読んで、記録した日に自動で○（黄色）。自動の○は、つづくでは外せない
  - 読めるのは同じブラウザで開いたときだけ（iPhone では LINE の中・Safari・ホーム画面のアプリで置き場所が別）。キロっくは LINE の中で使うので、つづくも LINE の中で開いたとき
  - 一度読んだ日は、つづくの記録（`auto`）に覚えておく。キロっくは新しい 10 回分しか残さないが、つづくの○は消えない。控えの書き出し・読みこみにも入る
- 📅 カレンダー・ふりかえり：「🗓 すべて」（習慣を重ねて、できた数を色の濃さで。全部できた日がいちばん濃い。日を押すとその日の ✅⬜。この月の全部できた日・1つ以上できた日・全部つづいている日数）と、習慣ごとのひと月の○（押すとつけ外し）、この月の日数と割合・いま続いている日数・いちばん長く続いた日数
- 💬 LINE で送る：おくるんのお知らせカード（`OQRN.cardUrl`）に、今日の○の一覧と続いた日数を渡す。色はロゴの青（#2F80D8）、ボタンは「✅ つづくで○をつける」。流入口は `from=tuzuq`
- 🔔 カレンダーでお知らせ：お知らせの時刻（はじめは 21:00）を決めて、習慣ごとに「Google」（毎日くり返す予定。Google の「タスク」はリンクから作れないので予定で）か「📥 まとめてカレンダーに入れる」（.ics。iPhone は「すべてを追加」、時刻ちょうどのお知らせつき）。予定の中に、つづくを開くリンク（`?h=習慣の id`。開くとその習慣まで動いて少し光り、まだなら「右の○を押してね」と出る。印はアドレスから消す）。止めるときはカレンダーの予定を消す（js/remind.js）。サーバーは使わない
- 💬 LINE でも記録（自分用）：自分の記録ボット（LINE の公式アカウント）の ID（@ から）を入れると、習慣を直す画面に「送る文」（例：`# workout`）が出る。今日の○をつけると、お知らせに「💬 LINE でも記録」が出て、押すとボットのトークが送る文入りで開く（`https://line.me/R/oaMessage/@ID/?文`）。送るのは自分なので、つづくは書きこみ用の鍵を持たない。ID を入れていない人には「送る文」は出ない
- 💬 LINE で使う：ブラウザで開いたときは、上に「📱 LINE で開くと…［💬 LINE で開く］［👀 使い方を見る］」の帯（✕ で閉じると、その端末では出さない）。「💬 LINE で使う」の欄に、LINE の画面に似せた4コマ（1. LINE で開く・2. ○を押す・3. カードで送る・4. 毎晩まとめが届く）。自分の記録ボットとつなぐ設定は「⚙️ くわしい人向け」にたたんである
- 💬 LINE の中（LIFF）で開いたとき（自分の記録ボットとつなぐ）：「💬 LINE でも記録」に自分の GAS（LOgBOT の複製）の URL を入れると、送る文のある習慣は、今日の○を押すだけでその GAS に1件入る（5秒は「元に戻す」で取りやめ。閉じるときはすぐ送る）。開いたときに GAS で記録した日を読み、○にする（黄色。外せない）。送るのは LIFF の ID トークンと送る文・日付だけ。GAS の URL・LINE の鍵・GitHub の鍵は、つづくは持たない（URL は使う人が自分で入れ、URL の ?〜 からは受けとらない）。GitHub はその GAS につないだ人だけ。つなぎ方と約束は `docs/linelog-setup.html`、LINE の情報の使い方は `privacy.html`（js/linelog.js）
  - LINE の中で開いていないときは、上の「💬 LINE でも記録」（トークを開いて自分で送る）がそのまま使える
  - LIFF の ID（`js/line-config.js`）は、つづくの LIFF ができたら入れる。空のあいだは何も変わらない
- 🔒 記録の控え：書き出し（スマホは共有シート、パソコンはダウンロード）・読みこみ（同じ習慣は○を足す、ほかは加える）、すべて消す

## 記録の置き場所

この端末（ブラウザ）の localStorage の `tuzuq:v1` だけ。サーバーには送らない（前の名前の `tsuduq:v1` が残っていれば、それを読む）。

- `habits`：`[{ id, name, emoji, link, at }]`（`link` は `"shoquji"` か null）
- `done`：`{ 習慣の id: ["YYYY-MM-DD", ...] }`（自分でつけた○の日。自動の○はここに入れず、そのつど読む）
- `bot`：`{ 習慣の id: ["YYYY-MM-DD", ...] }`（LINE の中で開いたときに、記録ボットから読んだ「記録した日」。日付だけ）
- `gasUrl`：つなぐ自分の GAS の URL（秘密ではない。形を確かめて残す）

## つなぐツールをふやすには

`js/store.js` の `LINKS` に足して、`linkedDays()` にその記録から日付を取り出す書き方を足す。ぽもくるは今は回数を残していないので、つなぐなら、ぽもくる側で「集中した日」を残すところから。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（スマホ前提。入力欄は 16px 以上、ページにも背景色）。部品はおくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`・`ui.js`）。`style.css` には、つづくの色と、つづくにしかない見た目だけ |
| `app.js` | 操作（○をつける・習慣をふやす・直す・カレンダー・カード・控え） |
| `js/store.js` | 記録の保存・つなぐツールの読みこみ・控え |
| `js/linelog.js`・`js/line-config.js` | LINE の中（LIFF）で開いたときの、記録ボットとのつなぎ。`line-config.js` に、つづくの LIFF の ID（画面に置いてよいもの。空なら使わない） |
| `js/stats.js` | 計算（日付・続いた日数・いちばん長く続いた日数・ひと月のカレンダー） |
| `tools/icon.py` | アイコン・ロゴ・OGP |

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q はカレンダーの○：白い輪の中にチェック、しっぽは右下からのびて輪の中に○をつけにいく黄色い手（ふちなし・ひとまとまり）
- 色は青（ほかの Q のツールと重ならない色）

## 公開するときにすること

1. GitHub に `katsuan/tuzuq` を作って push し、Pages を開く
2. 確かめがすんだら `index.html` の noindex を外す
3. おくるん（line-share）の `data/hub-links.json` に `key: "tuzuq"` を足す（グループは「毎日・あそび」）。`backup/app.js` の一覧に `["tuzuq:", "つづく", "tuzuq"]` を足す
