LINE の情報の使い方（プライバシーポリシー）

つづくが持つもの

  • 習慣と○の記録は、あなたの端末（ブラウザ）の中だけに残ります。つづくのサーバーはありません
  • つづくの作り手は、あなたの記録・LINE の情報を受けとりません

LINE の中で開いたとき

  • LINE ログインで受けとるのは、本人の確かめ用の印（ID トークン。中に LINE の ID と表示名が入っています）だけです
  • この印は、あなたが自分で入れた GAS（記録ボット）にだけ送ります。GAS は LINE に問い合わせて本人かを確かめるのに使い、印は残しません
  • GAS には、あなたの LINE の ID（持ち主の登録のため）と、記録（日付・行動名・送る文）が、あなたのスプレッドシートに残ります。それを持つのは、その GAS を用意した人（ふつうはあなた）です
  • 表示名は、持ち主の登録のときに、GAS の実行ログで本人か見分けるためだけに使います
  • つなぎ先を入れていなければ、つづくは何も送りません

やめるとき

  • つづくの「💬 LINE でも記録」のつなぎ先を空にすると、送らなくなります
  • LINE の「設定」→「アカウント」→「連動アプリ」から、つづくの連動を外せます
  • 端末の記録は「🔒 記録の控え」の「記録をすべて消す」で消えます。GAS の記録は、そのスプレッドシートから消します
